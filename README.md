# elixir-cloud-aai.github.io

The ELIXIR On-Cloud docs moved to https://docs.elixir-on.cloud/ (source:
[elixir-cloud-aai/docs](https://github.com/elixir-cloud-aai/docs)).

This repository only keeps the old home page working: GitHub Pages serves
`index.html` at https://elixir-cloud-aai.github.io/, which sends the browser
to the new site. Other paths of the old site are not redirected. Project pages
of other repositories (`elixir-cloud-aai.github.io/<repo>/`) are not affected.
